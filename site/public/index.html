An open accelerator, measured on real hardware

Inside a PCIe AI accelerator

Hailo-8 and NXP's Ara-2 are cards an embedded CPU hands work to over PCIe. This project builds one in the open, on an AMD Artix-7 FPGA driven by an NXP i.MX95, and follows every byte from the CPU through the IOMMU and the PCIe link into the card's memory and its matrix engine, which now runs a small neural network. Every number on this page was measured on the bench below, or is derived from one that was.

What the host submits for one image

Four 64-byte entries in the submission queue, then one write to the SQ_TAIL doorbell. The card fetches them over PCIe, runs them in order, and writes a 16-byte completion for each. Words are 64-bit, shown as hex; select one to see its fields. Layouts: command-queue.md.

      04 · Numbers

      Where the time goes, and how fast each path is

      Tags say where each number comes from: measured on the bench, derived from measurements, or spec from a standard or datasheet.

      MNIST, all 10 000 test images: images per second

      The same network, the same answers on all three, bit for bit. The first engine lost to one CPU core; holding 8 images on chip so each weight read does 8 times the work made it 4 times faster than the core.

      From one clock tick to one gigabyte

      Log scale: each grid line is ten times the one before.

      Measured bandwidth against each path's limit

      Bars are measured; the gray track is the limit for that path. The card's own memory is about fourteen times faster than the link that feeds it.

      XDMA throughput against transfer size (phase 2)

      Through AMD's XDMA driver each transfer paid about 40 µs of fixed cost, so small transfers wasted the link; above about 1 MiB the link itself was the limit. Since phase 3 the card fetches commands itself: a copy costs one 3.8 µs command.

      05 · Debugging on real hardware

      Instruments built into the card

      The card carries a logic analyzer on each side of its memory interconnect, a virtual control panel, and a JTAG path into DDR3, all reachable from Vivado with no host attached. Bring-up turned up four bugs worth telling: in the card's registers, in AMD's host driver, in a card engine before it shipped, and in the GEMM engine on the card itself. Each says how it was found.
